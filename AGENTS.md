# AGENTS.md — правила Codex для редизайна «Подписки»

Редакция 2.1, 16.11.2026. Документация — не разрешение на разработку. Работать по одному небольшому явно порученному этапу, не переписывать приложение целиком. Продукт уже существует; R0 принят, прежняя история разработки не перенесена. Приложение предназначено только для личного использования.

## Источники и приоритеты

Перед задачей прочитать PRD.md (поведение), UI_DESIGN_SPEC.md (согласованный дизайн, не переделывать), ARCHITECTURE.md, TEST_PLAN.md, IMPLEMENTATION_PLAN.md и актуальные исходники. docs/redesign/DECISIONS.md — трассировка 126 решений; позднее решение имеет приоритет над ранним. Утверждённая иконка №126 — docs/redesign/assets/launcher-approved.png; не менять дизайн и не заменять очищенный референс. docs/redesign/DEFERRED_BACKUP.md — H, вне личной версии. Если документы расходятся с кодом, это работа редизайна, не повод восстанавливать отменённые требования. Если документы расходятся между собой или нет нужного источника, остановить спорный участок и запросить согласование. Не изменять требования/документацию без поручения.

## Инварианты

- Офлайн, русский, Android12+, существующий Kotlin/Compose/Room/DataStore/WorkManager. Сохранить applicationId и проверенный стек, не добавлять зависимости без необходимости. Только RUB, цена в копейках Long, проверка переполнения, точная нормализация; не конвертировать иностранную сумму.
- Один календарь, один режим, состояния ACTIVE/CANCELLED/ARCHIVED. Никаких фактических платежей, истории, возвратов, подтверждений, проблемных статусов, автоархива, индивидуальных уведомлений, сроков отмены и разовых переносов. Не вычислять прошедшие даты как расходы. При изменении даты обновляется вся серия, опорный день сохраняется при календарном продлении. Даты LocalDate, время уведомлений местное.
- Отмена фиксирует конец доступа (первый день без доступа), сразу исключает из прогнозов и напоминаний, остаётся внизу списка. Архив вручную, восстановление с проверкой даты/цены/периода. Не отменять подписку у поставщика. Удаление явное с подтверждением.
- Главный экран — список, финансовых карточек нет. Статистика — today..today+30 включительно, годовая нормализация, 12 календарных корзин и сравнение месячной/годовой стоимости. Только активные; не выдавать расчёты за факты. Настройки — темы/анимации, единые уведомления {3,1} по умолчанию 09:00, архив. Островок 3 корня, скрытие панелей сохранено, без blur. Не копировать старые макеты с платежами. Доступность обязательна.
- Сохранить безопасную работу ассетов G-02b, generation gate/ledger, уведомления best effort без exact alarm. Отказ ОС не мешает пользоваться приложением. Не выдумывать успешную доставку. Без сети, аккаунтов, рекламы, аналитики, ненужных разрешений.
- Чистая база только ручной сброс тестовых данных владельцем перед приёмкой; не выполнять destructive migration/автоматическую очистку. Реальные данные в дальнейшем мигрировать. H отложен, не добавлять фиктивных кнопок и не включать Android Auto Backup/D2D. Не ослаблять контракт безопасного H.

## Работа по задачам

Проверить branch/HEAD и чужие изменения; согласовать базу, scope и ID требований/тестов. Не выполнять reset --hard, force push, удаление веток/данных, смену секретов/настроек, merge или публикацию без отдельного явного разрешения. Не создавать PR/ветку без согласования. Изменять только необходимые файлы, сохранять лицензии и Room schema snapshots, удалять отменённый runtime с контролем ссылок. Никакого перехода к следующей задаче автоматически. Если среда недоступна — документировать BLOCKED, не имитировать успех.

Команды при наличии среды:

```bash
./gradlew :app:testDebugUnitTest
./gradlew :app:assembleDebug
./gradlew :app:lintDebug
./gradlew :app:compileDebugAndroidTestKotlin
# только при реально подключённом устройстве/эмуляторе
./gradlew :app:connectedDebugAndroidTest
```

Windows — gradlew.bat. Проверять git diff --check, применимые тесты, не подменять ручную проверку TalkBack/Photo Picker/реальных уведомлений JVM-тестом. Экономить облачные CI: пакетировать проверки внутри небольшой законченной задачи, не обходить обязательные gates. Не заявлять, что CI запущен/пройден, если не запускался. Не копировать старые результаты.

## Отчёт по задаче (русский)

1. Цель, затронутые файлы, ID требований и тестов.
2. Что изменено, что сохранено, что вне scope; ссылка на diff/PR только если реально существует.
3. Команда, среда, SHA, результаты PASS/FAIL/NOT RUN/BLOCKED/NOT APPLICABLE с причинами, число реально выполненных тестов; known issues.
4. Риски, ручная проверка, остаточные ограничения и следующий шаг для владельца. Остановиться до нового поручения.

## Конфиденциальность репозитория

Не добавлять реальные пользовательские данные, базы, экспорт, фото, сведения о личных устройствах, адреса электронной почты, ключи, токены, пароли, локальные пути или логи реального устройства. Для тестов и примеров использовать только синтетические данные; автор и коммитер должны использовать GitHub noreply. Перед каждым коммитом проверить diff и метаданные; не раскрывать данные в PR, Issues и Actions. Сборки и CI запускать только согласно согласованной задаче.
