# Проверка согласованности документации

Редакция 2.1, принятая на этапе R0. Проверка согласованности документации, не проверка реализации редизайна. При переносе в новый репозиторий исключены исторические ссылки и персональные сведения. Снимок кода сохраняет прежнее поведение; R1a ещё не выполнен.

## 1. Проверка требований

| Область | Итог |

Старые решения (платежи, возвраты, фактическая аналитика, режимы, просрочки, отмена-напоминания, индивидуальные правила, разовые переносы, автоархив) присутствуют только в реестре отменённых требований, отрицательных критериях и плане удаления. Не являются задачами к реализации. Прежняя история и отчёты не перенесены.

## 2. Принятые технические конкретизации (не новые продуктовые решения)

- Восстановление календарной опоры и необязательное начало текущего периода сохранены из старого PRD в компактном раскрываемом разделе. Это предотвращает ошибку 28 февраля при опоре 31 и не требует отдельного обязательного поля. При первой будущей дате предшествующая граница расчётная, не подтверждённый платёж; при отмене старт фиксируется. Не вводить дополнительные сценарии сверх этого.
- Сохранены необязательная подпись аккаунта, явное ручное архивирование активной записи из прежней логики и проверка параметров при возобновлении. Порядок архива по дате, стабильный ID для tie-break, default выбранного месяца — технические детерминированные правила. Переключатель рейтинга сохраняется как адаптация №81.
- Нормализация использует стандартный 365-дневный год, ROUND_HALF_UP до копеек в отображении; календарный график — текущий неполный месяц и 11 следующих. Это разные оценки, не обязаны совпадать; сумма не выводится как факт. Подписи в UI уточняют смысл.
- №115–125 уточнили дизайн: компактный центрированный островок, мягкая капсула, alpha 0,85, крупный заголовок, просторные строки 54 dp, выравнивание и порядок графиков, редактор/детали/настройки. Не утверждённые численно размеры (например, ширина около 204 dp, шаг строк около 98 dp, alpha верхней панели 90–96%) остаются ориентирами, не новыми решениями; проверяются на устройстве. Отключение скрытия при активном TalkBack — техническая мера доступности, не новая настройка. Макеты в UI_DESIGN_SPEC — схемы состава экранов, не замена утверждённого дизайна.
- При несовместимой старой схеме — блокирующая инструкция до ручного сброса владельцем; не автоматический сброс. Сохранена инфраструктура поколений/ledger, чтобы не ухудшить надёжность уведомлений и будущий H. Конкретную версию новой Room и механизм обнаружения старой схемы определяет R1b.
- Утверждённый референс launcher №126 приложен без изменения пикселей; EXIF и дополнительные метаданные удалены: [launcher-approved.png](assets/launcher-approved.png). Не является готовым Android-ресурсом. R8 требует адаптации, сохранения геометрии/цветов и проверки масок; не менять дизайн.
- Перед R1a проверить актуальный HEAD, получить отдельное разрешение на задачу. Запуск CI, подпись и удаление данных требуют согласования.

## 3. Проверка покрытия

Реестр содержит 126 последовательных строк, без пропусков. PRD содержит 45 уникальных ID требований; TEST_PLAN — 47 уникальных тест-кейсов, включая отложенный H. Все ID требований упомянуты в тест-плане, все ссылки ID из реестра и тест-плана разрешаются в PRD. Требования вне нового интервью имеют явное основание в отдельной таблице наследования. Локальные Markdown-ссылки проверены. Это структурная проверка, не доказательство выполнения тестов приложения.

Синтетические примеры календаря и арифметики приведены в TEST_PLAN. Полный запуск Android-тестов, сборка и lint нового снимка: NOT RUN. Финальная проверка оформления на физическом Android-устройстве остаётся впереди.
