# Происхождение и лицензия тематических значков G-02b

Проверено 05.11.2026. Источник — [официальный репозиторий Google Material Design Icons](https://github.com/google/material-design-icons), зафиксированный commit `10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7`. [README, раздел License](https://github.com/google/material-design-icons/blob/10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7/README.md) разрешает встраивать Material Symbols в продукты по [Apache License 2.0](https://github.com/google/material-design-icons/blob/10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7/LICENSE). Копия полной лицензии входит в APK как `app/src/main/assets/licenses/material_symbols_apache_2.0.txt`.

Использованы официальные `symbols/android/<source>/materialsymbolsoutlined/<source>_24px.xml`. Для совместимости с Quiet UI в локальных копиях удалён исходный theme tint и установлен нейтральный чёрный путь; Compose окрашивает его существующим токеном текста. Геометрия путей не изменена. Это уведомление фиксирует изменение исходных файлов. Отдельного `NOTICE` в корне источника при проверке не найдено.
