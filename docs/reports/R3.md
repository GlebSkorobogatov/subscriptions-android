# R3 — согласованная дизайн-система Quiet UI

## Ревизия и статус

Исходная ветка `codex/r2b-renewal-reminders`, принятый SHA `d24a271844ac0269776b577791ff32279de3fa07`, Draft PR #8.
Перед изменениями HEAD совпал, дерево было чистым. Ветка `codex/r3-design-system` создана непосредственно от принятого SHA.
Итоговый SHA проверенной реализации: 3363e1dc4bda36042b82e326e0fcd1f6cb0a86fb. Отчёт добавляется документационным коммитом поверх него;
окончательный tip указан в stacked Draft PR и сообщении владельцу.

Использованы AGENTS.md, PRD, UI_DESIGN_SPEC 2.1, ARCHITECTURE, IMPLEMENTATION_PLAN, TEST_PLAN,
DECISIONS и материалы принятых R1–R2, включая исправления и device backlog.
В репозитории единственный растровый согласованный исходник — launcher-approved.png: он относится к R8 и не изменён.
Для компонентов источником служит спецификация, а не старые макеты с отменённым поведением.
Решение владельца о фиксированном 09:00 сохранено; продуктовые документы не менялись.

R3 ограничен общей визуальной основой и минимальным подключением общих компонентов. Новые главный экран,
навигация, настройки, редактор, детали и статистика не реализованы. Полная визуальная приёмка **NOT RUN**.

### Контраст и обоснование коррекции

Утверждённые background #FFFFFF/#212121 не корректировались. Прочие старые нейтральные поверхности приведены
к точным исходным ролям спецификации. Единственная дополнительная коррекция согласованной исходной роли:
**DARK textSecondary #B1B4BA → #BFC2C8**, поскольку на selectedTabBg=#505050 исходное значение давало **3,881:1**,
а новое даёт **4,518:1**. Порог для обычного текста — 4,5. Коррекция центральная, локальных обходов на экранах нет.

Не требуются декоративные яркие поверхности, градиенты, dynamic colors или blur; они не добавлены.
Контраст панели с будущей alpha=0,85 на реальном контенте проверяется в R4a, не объявлен пройденным здесь.

## Типографика, геометрия и анимации

- Системный SansSerif, без скачивания. Заголовок 28sp SemiBold; секции 18/20sp SemiBold;
  название 16sp Medium; суммы 28/30/32sp SemiBold с fontFeatureSettings=tnum; подписи 13/14sp;
  группы настроек 12/13sp Medium. LineHeight в sp масштабируется; высоты текстовых блоков не фиксируются.
- TrackerMoney и formatTrackerRub используют прежний точный Money.format(), группируют разряды и убирают
  только нулевые копейки: `1 990 ₽`, `299,50 ₽`, `0,01 ₽`, `92 233 720 368 547 758,07 ₽`.
  Нет Double/Float денежных вычислений, конвертации или изменения Money/RubPrice.
  Пробелы позволяют крупной сумме переноситься. Компонент подготовлен в gallery; массовый перевод старых
  денежных подписей экранов оставлен их R4–R6 этапам, чтобы не расширять R3.
- Отступ 20dp, helper для ширины <360dp — 16dp; секции 24dp, внутренние 12/16dp; modal padding 24dp.
- Card radius 22dp, field 16dp, default subscription icon 54×54dp/radius 15dp; primary ≥52dp, touch ≥48dp.
  98dp — только reference токен шага строки, не ограничение высоты. Существующее увеличение иконки/переносы
  строки при крупном шрифте сохранены. Поле, текст и кнопки растут по содержимому.
- Motion token — 220ms. Общий helper возвращает 0 при отключённых анимациях или systemScale≤0;
  положительная шкала — номинальные 220ms, системный Compose MotionDurationScale применяется клиентом без двойного умножения.
  Material controls сохраняют штатный системный механизм. Новый DataStore flag/toggle и scroll hiding не введены.
  Фактический reduced motion на Android — NOT RUN; подключение пользовательской настройки — R4b.

## Общие компоненты и минимальная интеграция

TrackerSurface поддерживает plain/subtle/raised/modal; мягкие поверхности без постоянных рамок.
TrackerPrimaryButton/Secondary/Text/Icon/Destructive и SelectedCapsule используют одни роли и touch minimum.
Loading primary выключает действие, сохраняет подпись и объявляет pending; существующая VM-защита повторного Save не изменена.
Selected capsule использует primary/medium для выбранного текста и secondary для обычного/disabled; имеет check, selected/stateDescription и radio/checkbox semantics, поддерживает single/multiple/disabled.

Поля имеют нейтральную заливку, прозрачную unfocused/disabled границу и видимую focused/error границу;
ошибка также передаётся supporting текстом и Semantics.error. Сохранены test tags, read-only/disabled, keyboard options,
добавлена совместимая поддержка KeyboardActions/supportingText. Формулы и правила editor validation не менялись.

TrackerStatusLabel даёт читаемый вторичный статус отмены без alpha всей строки.
TrackerError не решает, какой вид ошибки произошёл: caller передаёт конкретный текст и retry callback.
Существующие storage blocked, forecast error и calendar error не объединены и не заменены Empty.
TrackerSuccessCapsule — stateless polite live region; ничего не сохраняет и не объявляет успех самостоятельно.
В gallery это явно учебный пример. Привязка к новой навигации/нижней безопасной зоне — последующие этапы.

TrackerConfirmationDialog сохранил confirm/dismiss/busy/Back callbacks, paneTitle, scroll и отдельное опасное действие.
Единый modal title 20sp, на коротком окне заголовок остаётся частью прокрутки без уменьшения fontScale.
TrackerBottomSheet — общий raised контейнер с прокруткой и imePadding; окончательные calendar/icon picker sheets не реализованы.
TrackerPageHeader сохранил safeDrawing padding, доступные русские Back/Settings labels и wrapping;
общие icon controls контурные и ≥48dp.

### Индикатор периода

Один TrackerPeriodIndicator используется строкой подписки и деталями. Он принимает готовые fraction/days/state,
не вычисляет даты, циклы или начало периода. Details теперь также использует готовый remainingDays домена.
Проверка стиля выполняется в Double; SubscriptionCardModel сохраняет доменный Double вместо прежнего Float.
Преобразование во Float происходит только для Canvas geometry/доступного ProgressBarRangeInfo.

| Вход | Стиль |
|---|---|
| 20%, 3 дня | soon/amber |
| >20%, 3 дня | нейтральный |
| 20%, >3 дней | нейтральный |
| Сегодня, корректная доля 0% | soon; 0% остаётся пустой линией, фиктивная заполненная часть не рисуется |
| Неизвестная/NaN/непредставимая/вне диапазона доля | нет визуального прогресса; корректные дни остаются отдельным текстом |
| CANCELLED, корректная проекция до конца доступа | читаемый вторичный стиль |
| ARCHIVED / домен скрыл отменённый период | нет линии |

Линия 4dp с округлёнными торцами, при 100% заполнена полностью, при 0% только track, без stop dot.
Сохранены прежние subscription/details progress tags. Semantics сообщает статус, процент оставшегося расчётного периода
и range; дата/дни показываются отдельно и не зависят от наличия доли.
Регрессия card→indicator проверяет реальную 5-дневную серию: один день = точные 20%, без ошибки 0.2f.toDouble()>0.2.
Погрешность не скрывается epsilon-сравнением; значение чуть выше 20% остаётся нейтральным.
