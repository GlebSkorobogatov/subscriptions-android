# ADR-14 — тематические значки вместо брендового каталога

Дата: 05.11.2026. Статус: утверждено владельцем в задаче G-02b.

Первая личная версия использует ровно 12 универсальных тематических векторов: музыка, видео, игры, ИИ, финансы, облако, книги, работа, обучение, спорт, покупки и другое. Они служат только оформлением подписки. Ни категорий, ни фильтров, ни аналитики по ним нет. Выбор значка не подставляет название или финансовые поля.

Один источник оформления активен одновременно: личное изображение из G-01 либо тематический значок. Отсутствующее оформление, неизвестный ID и устаревшие брендовые ID визуально разрешаются в «Другое». Старое значение `catalogLogoId` в Room не переписывается при чтении или обычном редактировании; новый выбор заменяет его. Префикс новых стабильных ID `generic-` исключает пересечение с прежними. Поле Room и схема v4 остаются неизменными.

В APK не включаются логотипы и названия компаний. Векторы взяты из официального Google Material Symbols с лицензией Apache 2.0 и уведомлением в `G-02b-icon-license.md`; копия лицензии включена в APK.

Решение уточняет актуальное требование R-SUB-05. Личная приёмка, G4, PERSONAL-READY и отложенный H этим ADR не закрываются.
