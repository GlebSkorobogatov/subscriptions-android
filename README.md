# Подписки · subscriptions-android

Android 12+ · Kotlin · Jetpack Compose · локальный менеджер подписок. Целевая редакция 2.1 от 16.11.2026, после 126 согласованных решений. Проект предназначен для личного использования; распространение приложения через магазины не планируется. Видимость исходного кода не означает публикацию приложения. **Исходный код ещё не переработан по этому комплекту.**

Три корня: «Подписки» (только список), «Статистика» (30 дней, нормализованный год, 12 календарных месяцев и сравнение стоимости), «Настройки» (оформление, общие напоминания, архив). Единое автоматическое вычисление дат, ручная отмена/архивирование, только RUB. Нет реального учёта платежей, возвратов или двух режимов продления. Приложение не списывает деньги и не отменяет подписку у поставщика.

## Базовое состояние и сборка

R0 (документация 2.1) принят. Этот репозиторий содержит чистый снимок существующего кода; R1a и последующие этапы ещё не реализованы. Результаты прежних проверок не подтверждают этот снимок. Перед каждой задачей проверять актуальный HEAD.

Существующий стек: JDK21 LTS (javac), Java/Kotlin target17, SDK Platform36/Build Tools35.0.0, Gradle Wrapper8.13, AGP8.11.1, Kotlin/Compose Compiler2.2.21, Compose BOM2025.10.01, min31/compile36/target36. Версии закреплены в gradle/libs.versions.toml, проверить фактический код. Не менять версии без обоснования и согласования.

Windows: совместимая Android Studio, SDK Manager, полный JDK21 в Gradle JDK и JAVA_HOME; Gradle Sync, локальный local.properties не в Git. `./gradlew` (Windows `gradlew.bat`) :app:testDebugUnitTest, :app:assembleDebug, :app:lintDebug, :app:compileDebugAndroidTestKotlin; :app:connectedDebugAndroidTest только при доступном устройстве/эмуляторе. Приёмка на физическом Android-устройстве обязательна.

## Важные ограничения

- №114: чистая тестовая база только после ручного сброса владельцем перед приёмкой. Не стирать данные автоматически при обновлении. Реальные данные впоследствии требуют миграций.
- Без H потеря устройства/данных может быть необратимой, архив не backup. H-01…05 — отдельная отложенная функция для личного использования. Системный Auto Backup/D2D отключён. Не разрабатывать H без отдельного задания.
- Утверждённый знак launcher — колокольчик внутри незамкнутого кольца, белый фон, графитовый знак. Утверждённый референс №126 с удалёнными метаданными (пиксели сохранены) включён: [launcher-approved.png](docs/redesign/assets/launcher-approved.png). Это исходный презентационный растр, а не готовый adaptive icon. В R8 адаптировать к Android, сохраняя символ, цвета и пропорции; удалить только внешнюю тень и окружение.
- Этот комплект не даёт разрешения на изменения исходников, веток, данных или распространение приложения. Следующий этап — R1a по отдельному заданию.

## Конфиденциальность разработки

В Git не добавлять пользовательские базы, экспорт подписок, изображения пользователей, личные сведения, ключи, пароли, токены и логи реального устройства. Использовать синтетические тестовые данные и скрытый GitHub email (`noreply`). Не загружать личные данные в Issues, PR или CI. Старый workflow привязан к прежним веткам; новые проверки включаются отдельным согласованным заданием.
